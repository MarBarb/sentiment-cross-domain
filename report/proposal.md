## 1. 问题定义(Problem Definition)

### 1.1 研究背景与动机

情感分类在影评、商品评论等标准语料上已接近性能饱和,但在真实社交媒体的社会事件评论场景下,模型准确率通常会出现显著衰减(常见 10–25 个百分点)。其根本原因并非模型容量不足,而是**源域(影评/书评)与目标域(社会事件讨论)之间存在显著的分布偏移(Distribution Shift / Concept Drift)**:目标域存在更多反讽、网络用语、政治/社会议题相关术语、以及短文本与长文本混杂的情况。

因此本项目不把"在 SST-2/IMDB 上训练一个 BERT 分类器"作为目标,而是聚焦于一个 **data-centric** 的问题:**在无法获得大规模目标域标注数据的前提下,如何通过数据层面的诊断(分布差异度量)、数据层面的增强(弱监督伪标注、OOD 样本筛选)与轻量的领域适配,量化并缩小跨域性能衰减?**

**业务价值**:为舆情分析、政府应急响应、品牌公关提供一套可快速迁移到新事件/新话题的情感倾向识别方案,降低每次新事件都重新大规模标注的成本。

**学术价值**:提供一个可复现的跨域情感分类评测基准,对比"纯模型改进"与"数据中心化改进"在 OOD 场景下的相对贡献。

### 1.2 任务形式化

设源域 $\mathcal{D}_s = \{(x_i^s, y_i^s)\}_{i=1}^{N_s}$,其中 $x \in \mathcal{X}$ 为文本,$y \in \mathcal{Y}=\{0, 1\}$(负面/正面)。
设目标域 $\mathcal{D}_t = \{x_j^t\}_{j=1}^{N_t}$,仅有少量 $N_t^L \ll N_t$ 的人工标注样本。

令源域、目标域文本特征分布分别为 $P_s(\phi(x))$、$P_t(\phi(x))$,其中 $\phi(\cdot)$ 为 BERT 编码器。

**目标**:学习分类器 $f_\theta: \mathcal{X} \to \mathcal{Y}$,最小化目标域期望风险:

$$
\min_\theta \ \mathbb{E}_{(x, y) \sim \mathcal{D}_t}\big[\ell(f_\theta(x), y)\big] + \lambda \cdot \mathrm{KL}\big(P_s(\phi(x)) \,\|\, P_t(\phi(x))\big)
$$

其中第一项在目标域少量标注集上估计,第二项通过领域适配层拉近两域特征分布。

**评估对象**:跨域性能衰减 $\Delta F_1 = F_1^{(s)} - F_1^{(t)}$,我们希望在保持源域性能的同时最小化 $\Delta F_1$。

## 2. 数据来源证明与初步探勘(Data Sourcing & Initial Audit)

### 2.1 数据来源

| 数据集 | 用途 | 获取方式 | 访问状态 |
|-------|------|---------|---------|
| SST-2 | 源域训练 | HuggingFace `glue/sst2` / Kaggle | 已下载 |
| IMDB | 源域训练 / 跨域测试 | Kaggle `lakshmi25npathi/imdb-dataset-of-50k-movie-reviews` | 已下载 |
| 社会事件评论 | 目标域 | 自建 Python 爬虫(微博、知乎热议话题、豆瓣小组) | 爬虫原型已跑通,首批 ~3k 条已入库 |
| 领域词典 | 特征增强 | HowNet 情感词典 + 网络用语词典 + 人工补充 | 已获取 |

### 2.2 数据规模与特征

- **SST-2**:约 67k 训练样本,平均长度 ~10 词,二分类,标签均衡。
- **IMDB**:50k 长评论,平均长度 ~230 词,二分类,标签完全均衡。
- **目标域自建数据**:预计爬取 8–10k 条原始评论,经清洗与去重后保留 ≥ 5k 条有效样本。长度分布与 SST-2、IMDB 均不相同(预计均值 ~40 词,重尾分布)。
- **特征维度**:统一使用 BERT tokenizer,截断长度 128 / 256 两档。

### 2.3 数据初步挑战(关键点)

1. **显著的概念漂移(Concept Drift)**:影评语料中"好/坏"主要围绕剧情、演技;社会事件评论中则涉及政策、群体、人物立场,词汇分布与情感触发词都有本质差异。预计初步 KL 散度 > 1.0。
2. **类别不平衡**:热点社会事件的评论常呈现负面偏重(经验估计负:正 ≈ 2:1 到 4:1),与源域均衡分布不一致,会放大跨域衰减。
3. **标签噪声 & 弱监督**:爬取数据没有天然标签,人工全量标注成本高,因此必然是"少量金标 + 大量银标"的弱监督场景。
4. **文本噪声**:表情符号、话题标签(#xxx#)、@mention、广告 / 复读机评论,需要专门的清洗规则。
5. **反讽与隐式情感**:目标域中反讽比例高于源域,是已知的 BERT 分类痛点。

第 3 周起将产出一份《数据审计报告》,量化上述每一项(缺失率、长度分布、类别分布、KL 散度、反讽样本占比的人工抽样估计)。

## 3. 初步方法与技术栈(Preliminary Methodology)

### 3.1 基线模型

- **B0**:TF-IDF + Logistic Regression(经典浅层基线,验证任务下限)。
- **B1**:BERT-base 在源域全量微调,直接 zero-shot 用于目标域(验证"不做任何适配"的跨域衰减基准)。

### 3.2 核心算法 / 技术方案

围绕 **data-centric + 轻量领域适配** 两条线展开,这是区别于"套用现成包做分类"的关键:

1. **数据层面(Data-Centric)**
   - **分布偏移诊断**:对源域、目标域分别计算词频分布、BERT `[CLS]` 向量分布的 KL 散度与 MMD,给出可视化的 shift 热图。
   - **弱监督伪标注**:用 B1 模型 + 领域词典规则对目标域未标注数据做双通道伪标注,仅保留两通道一致且置信度 > τ 的样本,构成"银标集"。
   - **OOD 样本筛选**:基于特征距离筛掉与源域过于相似的"简单样本",强制模型接触真正困难的目标域样本。

2. **模型层面(轻量领域适配)**
   - **M1 – 领域适配层(DAL)**:在 BERT 编码器上追加一个小型适配器(Adapter / LoRA),仅训练适配器参数,避免过拟合小目标域标注集。
   - **M2 – 对抗域判别(DANN 思想)**:加入域判别器,通过梯度反转层学习域不变特征。
   - **M3 – 可选扩展**:RoBERTa、XLNet 替换 backbone 的对比。

### 3.3 技术栈

- **建模**:PyTorch、HuggingFace Transformers、PEFT(LoRA)
- **弱监督**:Snorkel(规则标注函数框架)
- **基线 / 特征**:scikit-learn、jieba
- **数据工程**:requests / Selenium、BeautifulSoup、pandas、SQLite
- **实验追踪**:Weights & Biases 或 TensorBoard
- **可视化**:matplotlib、seaborn

## 4. 实验设计与评估指标(Experiment Design & Metrics)

### 4.1 评估指标

**技术指标**

- Accuracy(参考用,不作为主指标)
- **Macro-F1 与 Weighted-F1**(主指标,应对类别不平衡)
- **AUC-ROC**(阈值无关)
- **跨域性能衰减 $\Delta F_1$**(本项目的核心指标,目标 ≤ 15%)
- **KL / MMD 分布距离**(数据层面诊断指标)

**业务指标**

- 目标域负面情感 Recall ≥ 85%(漏报负面对舆情业务代价最大)
- 人工抽样一致性 Cohen's Kappa ≥ 0.7(保证标注质量)

### 4.2 消融 / 对照实验设计

为证明每一处改动的独立贡献,设计如下消融矩阵:

| 实验 ID | 模型 | 源域训练 | 弱监督伪标 | 领域适配层 | 对抗域判别 | 主要验证点 |
|--------|------|---------|-----------|-----------|-----------|-----------|
| E0 | TF-IDF+LR | ✓ | ✗ | ✗ | ✗ | 浅层基线下限 |
| E1 | BERT | ✓ | ✗ | ✗ | ✗ | 跨域衰减基准 |
| E2 | BERT | ✓ | ✓ | ✗ | ✗ | **弱监督增强的独立贡献** |
| E3 | BERT | ✓ | ✗ | ✓ | ✗ | **适配器的独立贡献** |
| E4 | BERT | ✓ | ✓ | ✓ | ✗ | 两者组合 |
| E5 | BERT | ✓ | ✓ | ✓ | ✓ | 完整方案 |
| E6 | RoBERTa | ✓ | ✓ | ✓ | ✓ | backbone 替换对比 |

核心对照:E1 vs E3(验证适配器)、E1 vs E2(验证弱监督)、E4 vs E5(验证对抗训练)。

所有实验统一三随机种子求均值与标准差,避免结论被单次随机性误导。
