# Final Defense Materials

本目录是最终答辩材料包。

## 文件清单

- `final_defense_7min.pptx`：7 分钟课堂汇报 PPT，共 10 页。
- `final_defense_contact_sheet.png`：PPT 缩略图总览，用来快速检查页序和视觉效果。
- `speaker_notes_7min.md`：逐页讲稿，按 7 分钟准备。
- `system_demo_3min_script.md`：3 分钟以内系统演示视频脚本。
- `recording_guide.md`：怎么录屏、怎么拍、每一步展示什么。
- `system_architecture.mmd`：系统架构 Mermaid 源码，可放进报告或备用展示。
- `defense_checklist.md`：上台前检查清单。

## 推荐使用顺序

1. 先打开 `final_defense_7min.pptx`，按 `speaker_notes_7min.md` 练 2 遍。
2. 再按 `system_demo_3min_script.md` 录制系统演示视频。
3. 录屏前用 `defense_checklist.md` 检查文件、命令、声音和窗口。
