# Final Defense Materials

本目录是最终答辩材料包。

## 文件清单

- `汇报PPT.pptx`：扩展版课堂汇报 PPT，共 20 页。
- `汇报PPT_10页原版备份.pptx`：扩展前 10 页原版备份。
- `演讲稿.md` / `演讲稿.pdf`：扩展版逐页讲稿，按约 14 分钟准备。
- `演讲稿_原版备份.pdf`：扩展前讲稿 PDF 备份。
- `final_defense_contact_sheet.png`：PPT 缩略图总览，用来快速检查页序和视觉效果。
- `speaker_notes_7min.md`：与 `演讲稿.md` 同步的逐页讲稿 Markdown。
- `system_demo_3min_script.md`：3 分钟以内系统演示视频脚本。
- `recording_guide.md`：怎么录屏、怎么拍、每一步展示什么。
- `system_architecture.mmd`：系统架构 Mermaid 源码，可放进报告或备用展示。
- `defense_checklist.md`：上台前检查清单。
- `generate_expanded_presentation.js` / `render_speaker_notes_pdf.py`：用于重新生成扩展版 PPT 与讲稿 PDF 的脚本。

## 推荐使用顺序

1. 先打开 `汇报PPT.pptx`，按 `演讲稿.pdf` 或 `演讲稿.md` 练 2 遍。
2. 再按 `system_demo_3min_script.md` 录制系统演示视频。
3. 录屏前用 `defense_checklist.md` 检查文件、命令、声音和窗口。
